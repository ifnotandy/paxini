## 维护约定

- **改 `data.h5` 字段**：`HDF5结构说明.md`、`Cap_Quest/README.md`、根 `README.md`
  三处同步（见根 README §0.4）。`HDF5结构说明.md` 被用户手动编辑过，**只可定点修改，
  禁止整份重写**。
- **新增文档**：放进 `DOC/`，并在这份索引的目录树与"想知道什么"表里各加一行。
- **新增图**：放 `DOC/figures/`，文档里写相对路径 `figures/xxx.svg`。
- **改了行为 / 参数**：`Cap_Quest/README.md` 的参数表与 FAQ 一起改；
  验完一项就把结论写进 [`待验证清单.md`](待验证清单.md) 对应行（实测值 + 命令 +
  取证方式，别只写"通过"）。真机实测数据**只在清单里记一份**，其他文档引用时给结论
  加链接，不整段复制。
- **决定不做的事**：进 [`待验证清单.md`](待验证清单.md) 的 E 组，写清理由，
  避免以后重复讨论。
